## Milestone 1 — 基礎 3D 地圖（完成，2026-11-16）

- [x] Angular 專案、建置、測試、lint、格式化
- [x] 真實高程的立體地形（約 0.4 公里一格，高度誇張 30 倍）
- [x] 平移、旋轉、傾斜、縮放，以及回到全圖
- [x] 26 個城市標記，點選後聚焦並顯示資訊
- [x] 59 條河流，其中 8 條有名稱標籤
- [x] 介面文字與資料文字保留多語系結構
- [x] 畫面上說明目前只有地理底圖、不含歷史資料

尚未做到的（已知限制）：

- 重要交通路線（鐵路、公路）還沒有畫。
- 1941 年的國界與分界線、當時的地名屬於歷史資料，留到 Milestone 3。
- 滑鼠右鍵旋轉只用模擬事件測過，還沒有真人實際操作確認手感。

## Milestone 2 — 時間軸（完成，2026-11-16）

- [x] 時間以「距 1941-06-22 的天數」表示，不用 JS Date
- [x] 時間軸與世界狀態的核心是純函式，有單元測試（前進、倒轉、邊界）
- [x] 時間軸介面：播放、暫停、拖曳日期、顯示目前日期，另可調整播放速度
- [x] 播放時地圖持續重繪，暫停時恢復閒置
- [x] 用明確標示為「示範」的假資料把機制跑通，不放任何未查證的史實

尚未做到的（已知限制）：

- 介面沒有倒轉播放的按鈕（核心支援負的播放速度，倒轉目前靠拖曳滑桿）。
- 單位在相鄰兩天都有資料點時會在午夜直接換位置，平滑過渡留到 Milestone 4。
- 示範單位只是文字方框，還不是軍隊符號，也不能點選。
- 時間軸上沒有事件節點的刻度（事件資料在 Milestone 3）。
