## Milestone 1 — 基礎 3D 地圖（完成，2026-11-16）

- [x] Angular 專案、建置、測試、lint、格式化
- [x] 真實高程的立體地形（約 0.4 公里一格，高度誇張 30 倍）
- [x] 平移、旋轉、傾斜、縮放，以及回到全圖
- [x] 26 個城市標記，點選後聚焦並顯示資訊
- [x] 59 條河流，其中 8 條有名稱標籤
- [x] 介面文字與資料文字保留多語系結構
- [x] 畫面上說明目前只有地理底圖、不含歷史資料

尚未做到的（已知限制）：

- 重要交通路線（鐵路、公路）還沒有畫。
- 1941 年的國界與分界線、當時的地名屬於歷史資料，留到 Milestone 3。
- 滑鼠右鍵旋轉只用模擬事件測過，還沒有真人實際操作確認手感。

## Milestone 2 — 時間軸（下一步）

下面的項目是草案，還不能直接開工：先與使用者確認內容，再開始實作。

- [ ] 時間以「距 1941-06-22 的天數」表示，不用 JS Date
- [ ] 時間軸與世界狀態的核心是純函式，有單元測試（前進、倒轉、邊界）
- [ ] 時間軸介面：播放、暫停、拖曳日期、顯示目前日期
- [ ] 播放時地圖持續重繪，暫停時恢復閒置
- [ ] 用明確標示為「示範」的假資料把機制跑通，不放任何未查證的史實

## Milestone 3 — 部隊與事件資料

- [ ] 從參考影片整理明斯克段的事件清單，交使用者過目
- [ ] 資料型別：HistoricalEvent、HistoricalSource、MilitaryUnit、UnitPosition、WorldState、TimelineState、CameraKeyframe
- [ ] 至少五個經史料確認的事件節點，每筆附來源與可信度
- [ ] 德軍與蘇軍主要部隊在關鍵日期的位置，區分「史料確認」與「估計」
- [ ] 部隊標記（軍隊符號方框、番號、陣營），確認陣營標示方式
- [ ] 1941 年的國界與分界線、地名用法

## Milestone 4 — 動畫與敘事

- [ ] 部隊移動：關鍵日期之間插值，插值中的標記與史料錨點視覺上可區分
- [ ] 進攻箭頭與戰線
- [ ] 控制區色塊與包圍圈（標示為估計）
- [ ] 點選事件後鏡頭自動移動
- [ ] 敘事面板：標題、日期、描述、來源
- [ ] Story Mode 與 Explore Mode，共用同一份狀態
