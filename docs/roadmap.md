## Milestone 2 — 時間軸（完成，2026-11-16）

- [x] 時間以「距 1941-06-22 的天數」表示，不用 JS Date
- [x] 時間軸與世界狀態的核心是純函式，有單元測試（前進、倒轉、邊界）
- [x] 時間軸介面：播放、暫停、拖曳日期、顯示目前日期，另可調整播放速度
- [x] 播放時地圖持續重繪，暫停時恢復閒置
- [x] 用明確標示為「示範」的假資料把機制跑通，不放任何未查證的史實

尚未做到的（已知限制）：

- 介面沒有倒轉播放的按鈕（核心支援負的播放速度，倒轉目前靠拖曳滑桿）。
- 單位在相鄰兩天都有資料點時會在午夜直接換位置（後來在 Milestone 3 改成滑行，見 decisions D37）。
- 示範單位只是文字方框，還不是軍隊符號，也不能點選。
- 時間軸上沒有事件節點的刻度（事件資料在 Milestone 3）。

## Milestone 4 — 動畫與敘事（完成，2026-11-22）

- [x] 部隊移動：已提前在 Milestone 3 完成，做法改為畫面轉場的滑行，不新增插值位置（decisions D37）
- [x] 進攻箭頭：照 1942 年德軍圖集每晚的藍色箭頭讀，兩位讀圖者都讀到的才畫，剔除運輸箭頭，共 194 支，一直顯示（2026-11-22，decisions U23、U24、D55、D56；[research/minsk-arrows.md](research/minsk-arrows.md)）
- [x] 德軍前緣與推進範圍（估計）：每晚一條線，把圖集上每個緯度最靠東的德軍部隊符號連起來，線以西塗淡藍色（2026-11-18，decisions U16、U17、D46–D50）
- [x] 前緣後方的蘇軍（估計）：圖集畫在那條線以西的紅色封閉圈，11 個晚上有；「兩個包圍圈」由這裡呈現，不是事件節點
      （研究與方法見 [research/minsk-front-situation.md](research/minsk-front-situation.md)）
- [x] 點選事件後鏡頭自動移動（已在 Milestone 3 完成）
- [x] 事件面板：標題、日期、描述、來源（已在 Milestone 3 完成）
- [x] 故事模式（導覽）與自己探索，共用同一份時間軸狀態：14 站、逐句附依據的旁白，按「下一站」翻頁，站與站之間逐日播過，動到時間軸就讓開、可以從同一站繼續（2026-11-22，decisions U19–U22、D52–D54；[research/minsk-story.md](research/minsk-story.md)）

尚未做到的（已知限制）：

- 前緣線是「每個緯度最東邊的符號」連成的，畫不出口袋的形狀；6 月 24 日至 26 日比亞維斯托克突出部整個落在線的西邊。
- 外層包圍圈在圖集上要到 7 月 3 日才畫成封閉圈，所以畫面上比哈爾德日記記的合攏日晚四天出現；6 月 25、26 日與 7 月 1、2 日沒有紅色區塊。
- 線上三分之一的符號只有一位讀圖者讀到，沒有逐一複核。
- 紅色區塊只標最大的一塊；圈內的字要把游標移到標籤上才看得到，觸控裝置看不到。
- 色塊與箭頭不能關掉。
- 箭頭多半很短（中位數 14 公里），是個別部隊當晚的動向，看不出整個戰役的大方向；實線與虛線的差別圖集沒有說明。
- 箭頭只有 3 晚畫回原圖逐支看過，其餘 15 晚依兩位讀圖者的一致度。
- 故事模式只有中文；旁白沒有逐句的出處連結，只有每站的來源清單。
- 故事模式的鏡頭在小螢幕上沒有另外調整，面板可能蓋住鏡頭對準的地方。

## Milestone 5 — 品質驗證

- [x] 時間軸前後拖曳的一致性：隨機播放、拖曳、跳轉並在動畫中途打斷，畫面靜止後和直接跳到同一時刻完全相同（測試，decisions D58）
- [x] 事件與世界狀態的一致性：事件說德軍到達的地方，當晚都在前緣以西或 20 公里內（測試）；順帶發現推進範圍會在兩晚之間後退，改成累積（decisions U28、D57）
- [ ] 地圖操作與效能：300 次換日期後 DOM 與標籤數量不變、每次換日期主執行緒最多約 11 毫秒、主控台沒有錯誤；**畫面更新率還沒量到**（瀏覽器面板在背景時會被節流）
- [x] 不同螢幕尺寸（decisions U26、D59）：平板直放看得到整張地圖；說明框只在 1200 像素以上預設展開；觸控裝置顯示手指操作說明
- [x] 重要交通路線：1941 年已通車的 10 條主要鐵路，用今日線形，每條查過通車年份（decisions U25、U27、D60；[research/minsk-railways.md](research/minsk-railways.md)）

尚未做到的（已知限制）：

- 第一次載入約 7 MB 的地圖資料（地形 6.4 MB），行動網路上會慢。
- 觸控操作說明只在模擬器以外的真實觸控裝置上會出現，還沒有在實機上看過。
- 手機上地圖兩側會被切掉，事件面板蓋住地圖下半部（U26：手機能看、不破版即可）。
- 鐵路只畫 10 條幹線；線形是今日的鐵路，只檢查了每段的繞行比例，沒有逐段對照舊地圖；1939 至 1941 年的改軌距沒有查。
- 鐵路線形要重新產生時，公用的 Overpass 伺服器很忙，40 段要抓一到兩個小時（已抓的段落會快取）。
