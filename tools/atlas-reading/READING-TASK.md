# 讀圖任務說明（每位讀圖者都照這份做）

## 背景
`tiles/` 裡的圖片裁自德國陸軍總參謀部 1942 年出版的圖集《Der Feldzug gegen Sowjet-Russland》第 1 卷。每張原圖是 1941 年某一天**晚上**的東線態勢圖。
我已經把每天的圖裁成四格，並疊上**綠色的經緯線網**：

- 檔名 `tiles/MMDD-NW.jpg`、`-NE.jpg`、`-SW.jpg`、`-SE.jpg`（例如 `0628-NE.jpg` 是 1941 年 6 月 28 日晚的東北格）。四格拼成一個長方形，相鄰兩格有少量重疊。
- 範圍大約是東經 19–32 度、北緯 50–56.5 度。
- 綠線每 0.5 度一條（整數度的線較粗）。線的兩端在圖的四邊標了度數，例如「27.5E」「53.5N」。**經線與緯線都略微傾斜**，所以讀座標時要沿著綠線看，不能只看正上方或正左方的標籤。
- 距離換算：緯度 0.5 度約 56 公里；經度 0.5 度約 33 公里。

我在做一個歷史地圖，需要知道每天晚上「德軍最前面的部隊在哪裡」以及「哪些蘇軍被圍在後面」。你的工作是把圖上畫的東西照實讀出來，位置用經緯度報給我（估到 0.05 度）。
會有另一個人獨立讀同樣的圖，之後比對兩人的結果，所以：**看到什麼寫什麼，讀不清楚就寫「unsure」，絕對不要用你的歷史知識去補或去猜。**

## 圖例
- **藍色＝德軍，紅色＝蘇軍**（紅色是德軍當時的情報判斷，常帶問號）。
- **德軍部隊符號**：一段藍色的弧線，或一個藍色的橢圓／圓圈，旁邊或裡面有番號，例如「7.Pz.」「29.m.」「258.」「1.K.D.」「SS "R"」「213. Sich.」「V.A. 10.Pz」（V.A. 是先遣支隊）、「Tle. 14.m」（Tle. 是一部）。帶問號的也算。
- **下列藍色的東西不是部隊符號，一律不要當成部隊**：
  - 又長又細、沒有番號的藍色直線或折線（集團軍、集團軍群之間的分界線，常常一路畫到蘇軍後方）。
  - 帶小橫槓與圓點、旁邊寫著時間（例如「28.6. 16⁴⁰」）的藍色線（空中偵察的航線）。
  - 藍色箭頭。
  - 帶小旗的方塊（司令部）與旁邊的地名底線。
  - 單獨的羅馬數字（軍的番號，例如「XXXIX.m.」「XII.」）。
  - 文字方框。
- **紅色**：小橢圓加一個數字是一個蘇軍師；較大的封閉圈裡面寫著好幾個番號或一行字，是一群蘇軍；紅色箭頭是觀察到的移動方向。

## 每一天要讀出的東西

### 一、最前面的德軍部隊符號（front）
從最北（圖的上緣）到最南（圖的下緣），找出所有**最前面**的德軍部隊符號。判斷方式：
一個德軍部隊符號，如果在它的緯度上下各 0.15 度（大約半格綠線間距的三分之一）之內，**沒有任何其他德軍部隊符號比它更靠東**，它就是「最前面」的。
整張圖從北到南通常會有 12 到 25 個。北方集團軍群與南方集團軍群的也要讀，不要只讀中間。

每個符號記：
- `unit`：番號，照圖上抄（例如 `"7.Pz."`、`"Tle. 14.m."`）。
- `lon`、`lat`：這個符號**最靠東的那一點**的經緯度（弧線就取弧線最東端；橢圓取它的東緣）。
- `conf`：`clear`（清楚）、`rough`（大致，誤差可能到 0.2 度）或 `unsure`。
- `note`：有問號、被別的符號蓋住、番號讀不清等，寫在這裡；沒有就留空字串。

### 二、被德軍部隊符號圍在後方的紅色封閉圈（red）
找出所有符合以下兩個條件的**紅色封閉線圈**：
1. 圈裡寫著兩個以上的番號或一行字，**或者**圈的東西寬度至少 0.3 度（約 20 公里）。只有一個數字的小橢圓不用記。
2. 它位在第一項那些「最前面的德軍符號」的**西邊**（也就是在德軍前緣的後方）。

每個圈記：
- `text`：圈內的文字，照抄（看不清的字用 `?` 代替）。
- `outline`：沿著圈線順時針取 6 到 12 個點的經緯度 `[[lon, lat], ...]`。
- `north`、`east`、`south`、`west`：圈的北、東、南、西四個方向上，**離圈線最近的德軍部隊符號**的番號與大約距離，例如 `"28. (~10 km)"`；那個方向 60 公里內沒有德軍部隊符號就寫 `"none within 60 km"`。
- `conf`、`note`：同上。

如果圖上沒有這樣的圈，`red` 就是空陣列。

### 三、其他（notes）
用一兩句話寫你覺得重要或奇怪的東西：例如有一條很長但沒有封閉的紅線、某個區域符號太密讀不清、紅色方框裡的文字。

## 輸出格式
把結果寫成 **JSON** 檔（路徑在你的任務訊息裡）。每一天一個鍵，例如：

```json
{
  "0628": {
    "front": [
      {"unit": "8.Pz.", "lon": 26.55, "lat": 55.85, "conf": "clear", "note": ""},
      {"unit": "7.Pz.", "lon": 28.05, "lat": 54.05, "conf": "clear", "note": ""}
    ],
    "red": [
      {"text": "2 K.D. / 2 Pz.D. / 4 Pz.Br.", "outline": [[23.9, 53.3], [24.4, 53.35], [24.75, 53.2], [24.7, 53.0], [24.3, 52.95], [24.0, 53.1]],
       "north": "28. (~8 km)", "east": "29.m. (~15 km)", "south": "134. (~10 km)", "west": "263. (~5 km)", "conf": "clear", "note": ""}
    ],
    "notes": "…"
  }
}
```

上面例子裡的數字只是示範格式，不是答案。`front` 請由北到南排列。寫完後用 `python3 -c "import json;json.load(open('你的檔案'))"` 確認是合法的 JSON。

## 需要看得更清楚時
在這個資料夾裡執行（把經緯度換成你想放大的地方）：

```
../venv/bin/python zoom.py 0628 24.3 53.15 zoom/你的代號-0628-a.jpg
```

它會輸出該位置放大 3 倍的圖（寬約 1.6 度），一樣帶綠色經緯線。放大圖請存在 `zoom/`，檔名以你的讀者代號開頭。符號密集的地方（邊境附近、包圍圈周圍）建議都放大看。

## 規則
- 唯讀：不要修改 `tiles/`、`half/`、`orig/` 與任何 `.py`，也不要修改專案其他地方的任何檔案。
- **不要開啟或閱讀 `read/` 裡其他讀圖者的檔案**，也不要上網查這些部隊當天在哪。獨立性是這項工作的全部價值。
- 不確定就寫 `unsure`。寫錯比留白糟得多。
- 這份工作不需要上網，也不需要下載任何東西。
