# 讀圖任務說明：德軍的藍色箭頭（每位讀圖者都照這份做）

## 背景
`tiles/` 裡的圖片裁自德國陸軍總參謀部 1942 年出版的圖集《Der Feldzug gegen Sowjet-Russland》第 1 卷。每張原圖是 1941 年某一天**晚上**的東線態勢圖。每天裁成四格，並疊上**綠色的經緯線網**：

- 檔名 `tiles/MMDD-NW.jpg`、`-NE.jpg`、`-SW.jpg`、`-SE.jpg`（例如 `0628-NE.jpg` 是 1941 年 6 月 28 日晚的東北格）。四格拼成一個長方形，相鄰兩格有少量重疊。
- 綠線每 0.5 度一條（整數度的線較粗）。線的兩端在圖的四邊標了度數，例如「27.5E」「53.5N」。**經線與緯線都略微傾斜**，讀座標時要沿著綠線看。
- 距離換算：緯度 0.5 度約 56 公里；經度 0.5 度約 33 公里。

我在做一個歷史地圖，要把圖上**德軍（藍色）的箭頭**照原樣畫上去。請把圖上每一支藍色箭頭的位置與形狀讀出來，位置用經緯度（估到 0.05 度）。
會有另一個人獨立讀同樣的圖，之後比對兩人的結果，所以：**看到什麼寫什麼，讀不清楚就寫「unsure」，絕對不要用你的歷史知識去補或去猜。**

## 只讀這個範圍
東經 19.5 到 31.5 度、北緯 50.5 到 56.0 度之內的箭頭。箭頭只要有一部分在範圍內就要讀。

## 什麼算「藍色箭頭」
- **要讀**：藍色（德軍）的線，一端有**箭頭尖**（實心或空心的三角、或兩條斜線構成的尖）。線可以是直的、彎的，實線或虛線都算。常見的是從某個德軍部隊符號（弧線或橢圓）伸出去的箭頭。
- **不要讀**：
  - 紅色的箭頭（蘇軍）。
  - 沒有箭頭尖的藍線：集團軍之間的分界線（又長又細，常常一路畫到蘇軍後方）、部隊符號本身的弧線。
  - **空中偵察的航線**：帶小橫槓與圓點、旁邊寫著時間（例如「28.6. 16⁴⁰」）的藍線，就算末端有尖也不要讀，寫進 `notes` 即可。
  - 司令部旗號、文字方框。
- 一支箭頭如果分岔成兩個尖，記成兩支（共用同一段尾巴）。

## 每一支箭頭要記
- `points`：從**箭尾**到**箭頭尖**依序取 2 到 8 個點的經緯度 `[[lon, lat], ...]`。直的箭頭給兩個點（尾、尖）即可；彎的箭頭沿著線多取幾個點，最後一個點一定是**箭頭尖的頂端**。
- `style`：`solid`（實線）或 `dashed`（虛線或點線）。
- `unit`：箭頭是從哪個德軍部隊符號伸出去的，照圖上抄番號（例如 `"3.Pz."`、`"1.K.D."`）。箭尾不連著任何部隊符號，就寫離箭尾最近的德軍部隊符號，並在 `note` 寫「不相連」；附近 30 公里內都沒有就寫空字串。
- `label`：箭頭旁邊或線上寫的字（例如時間、日期、「V.A.」、問號），照抄；沒有就留空字串。
- `conf`：`clear`（清楚）、`rough`（大致，誤差可能到 0.2 度）或 `unsure`。
- `note`：箭頭被別的東西蓋住、看不清是不是偵察航線、與另一支箭頭交疊等，寫在這裡；沒有就留空字串。

## 輸出格式
把結果寫成 **JSON** 檔（路徑在你的任務訊息裡）。每一天一個鍵：

```json
{
  "0702": {
    "arrows": [
      {"points": [[29.25, 53.10], [29.55, 52.98], [29.75, 52.93]], "style": "dashed", "unit": "3.Pz.", "label": "", "conf": "clear", "note": ""}
    ],
    "notes": "…"
  }
}
```

上面例子裡的數字只是示範格式，不是答案。沒有任何藍色箭頭的那一天，`arrows` 給空陣列。寫完後用 `python3 -c "import json;json.load(open('你的檔案'))"` 確認是合法的 JSON。

## 做法建議
- 每一天先看四張圖，把藍色箭頭全部找出來（箭頭通常不多，一張圖大約幾支到二十幾支），再逐支放大讀座標。
- 放大：在這個資料夾裡執行
  ```
  ../venv/bin/python zoom.py MMDD 經度 緯度 zoom/你的代號-MMDD-a.jpg
  ```
  它會輸出該位置放大 3 倍的圖（寬約 1.6 度），一樣帶綠色經緯線。符號密集的地方請放大再讀。
- 一天讀完就先把那一天寫進 JSON 檔，不要等到全部讀完才寫。

## 規則
- 唯讀：不要修改 `tiles/`、`half/`、`orig/`、`read/` 與任何 `.py`，也不要修改專案其他地方的任何檔案。
- **不要開啟或閱讀 `arrows/` 裡其他讀圖者的檔案**，也不要上網查這些部隊當天往哪裡走。獨立性是這項工作的全部價值。
- 不確定就寫 `unsure`。寫錯比留白糟得多。
- 這份工作不需要上網，也不需要下載任何東西。
